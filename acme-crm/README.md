# Acme CRM

Full-stack application generated by the **Mosaic CLI**:

- **API** — Hono + PostgreSQL with metadata-driven entities, auto migrations and auto-generated CRUD
- **Web** — SvelteKit 5 **PWA** rendering your published forms (JSON) and pages
- **CLI** — `mosaic` for migrations, seeding and scaffolding

## Quick start

```bash
# 1. start Postgres (Docker) or point DATABASE_URL at your own
docker compose up -d

# 2. configure
cp .env.example .env

# 3. install & boot (API seeds admin + demo data on first run)
npm install
npm run dev
```

- API: http://localhost:8901
- Web: http://localhost:5610
- Default admin (when seeded): `admin@mosaic.local` / `admin1234`

## Model → migrate → CRUD loop

1. Add `entities/<name>.entity.json` (see `entities/customer.entity.json`).
2. `npm run migrate` — plans SQL (dry-run preview) then applies it.
3. Instant CRUD: `GET/POST/PATCH/DELETE /api/entities/<name>` (+ `/meta`, `/options`).

## Design forms & pages

Open the **Mosaic Studio** (`mosaic studio`) and drag & drop 50+ enterprise components.
Forms/pages are stored as JSON in `mosaic_forms` / `mosaic_pages`; publish, then visit
`/f/<form-slug>` or `/p/<page-slug>` in the web app.

## PWA

The web app is installable (manifest + service worker): shell is precached, `/api` is
network-first with offline fallbacks, and published forms work offline after first visit.

## CLI

```bash
mosaic entity Product --fields "name:string,price:decimal,stock:int"  # scaffold entity
mosaic migrate              # plan + apply migrations
mosaic seed --demo          # seed demo data
mosaic studio               # open the drag & drop studio
mosaic info                 # show project info
```
