# Road to v1

Use the [Cloud guide](./cloud-studio.md) and the [local quickstart](./quickstart.md) for current behavior. This page tracks work toward v1.

| Area | Work toward v1 |
| --- | --- |
| Business workflows | Reusable transitions, record-aware approvals, durable execution and retries |
| Authorization | Tenant isolation, record-level permissions and organization governance |
| Studio | Draft recovery, conflict resolution and broader data-source support |
| Deployments | Controlled promotion across environments, tested backup restoration and rollback |
| Integrations | Publish and validate new framework capabilities in installed apps |

Cloud can generate managed submission endpoints and produce an OpenAPI file. Use [server extensions](./extensions.md#server-extensions) for approval or balance workflows that need application-specific authorization and transactions.

See the [v1 plan](https://github.com/lethabomaepa11/mosaic-apps/blob/main/contributor-docs/v1-roadmap.md) and [tracked issues](https://github.com/lethabomaepa11/mosaic-apps/issues) for priorities and acceptance criteria.
