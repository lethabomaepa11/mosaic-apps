Mosaic 0.1 is here: define entities as JSON, get Postgres tables, migrations,
CRUD APIs with auth and audit, a 57-component drag & drop designer, and an
installable PWA — from one model.

<!-- truncate -->

```bash
npx @mosaic-apps/mosaic-cli create my-app
cd my-app && npm install && npm run dev
```

Read the [quickstart](/docs/quickstart), browse the [component
catalog](/docs/components/catalog), and tell us what you build.
