# @mosaic-apps/cli

The `mosaic` executable scaffolds full-stack Mosaic apps, manages entity
migrations and seed data, and provides project utilities.

```bash
npm install -g @mosaic-apps/cli
mosaic create "Acme CRM"
```

The package bundles the `templates/fullstack` scaffold during `prepack`.
Generated apps require Node.js 22 or newer and a PostgreSQL-compatible
database. See the Mosaic CLI documentation for options.
